# Calculus Exam Preparation Tool

A comprehensive web-based tool for practicing various calculus and linear algebra concepts. This interactive platform helps students prepare for exams by providing hands-on practice with different mathematical methods and techniques.

## 🚀 Features

### 1. Interpolation Methods
- Newton Interpolation
- Newton Divided Difference
- Lagrange's Interpolation

### 2. Linear Equation Solvers
- Gauss Jacobi Method
- Gauss Seidal Method
- Gauss Linear Jordan Elimination
- Gauss Inverse Jordan Elimination

### 3. Correlation Analysis
- Karl Pearson's Coefficient of Correlation
- Spearman's Rank Correlation Coefficient

### 4. Numerical Integration
- The Trapezoidal Rule
- The Simpson's 1/3 Rule
- The Simpson's 3/8 Rule

### 5. Matrix Operations
- Gauss Rank of Matrix
- Linear Equation Gauss Elimination

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/harshalgondaliya/Calculus.git
```

2. Navigate to the project directory:
```bash
cd Calculus
```

3. Open `index.html` in your web browser to start using the application.

## 💡 Usage Guide

1. Select a topic from the main menu
2. Choose the specific method you want to practice
3. Follow the on-screen instructions to input your data
4. View the results and step-by-step solutions

## 📝 Features in Detail

### Interpolation Methods
- **Newton Interpolation**: Estimate values between known data points
- **Newton Divided Difference**: Calculate polynomial coefficients
- **Lagrange's Interpolation**: Find polynomial passing through given points

### Linear Equation Solvers
- **Gauss Methods**: Solve systems of linear equations
- **Jordan Elimination**: Transform matrices to reduced row echelon form
- **Matrix Inversion**: Find inverse of square matrices

### Numerical Integration
- **Trapezoidal Rule**: Approximate definite integrals
- **Simpson's Rules**: Higher accuracy integration methods
